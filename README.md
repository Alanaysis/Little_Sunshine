# 🐦 Little Sunshine

一只住在你桌面上的小鸟，陪你度过每一天。

## 项目简介

**Little Sunshine** 是一款桌面宠物应用，让你在电脑桌面上养一只可爱的小鸟。通过孵化蛋、互动喂养、户外探索等玩法，体验养鸟的乐趣。

## 核心玩法

### 🥚 获得小鸟
- **孵蛋模式** — 通过完成任务或随机事件获得一枚蛋，经过耐心孵化后破壳而出
- **户外探索** — 从户外场景中发现并带回小鸟
- **直接领养** — 快速获得一只小鸟，立刻开始互动

### 💬 日常互动
- 喂食、清洁、陪玩
- 小鸟会在桌面上自由活动、跳跃、飞翔
- 不同的心情和状态会影响小鸟的行为表现

### 🌍 户外系统
- 户外场景探索，发现新的小鸟品种
- 收集图鉴，解锁更多小鸟种类
