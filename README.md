# 🐦 Little Sunshine

一只住在你桌面上的小鸟，陪你度过每一天。

## 项目简介

**Little Sunshine** 是一款桌面宠物应用，让你在电脑桌面上养一只可爱的小鸟。小鸟会在桌面上自由活动、跳跃、飞翔，你可以和它互动、喂食、摸摸头。

## 核心玩法

### 💬 日常互动
- 喂食、摸摸头
- 小鸟会在桌面上自由活动、跳跃、飞翔
- 不同的心情和状态会影响小鸟的行为表现
- 状态系统：心情、饥饿度、精力、亲密度

### 🎮 交互方式
- **右键菜单**：喂食、摸摸头、查看状态、退出
- **拖拽**：拖动小鸟移动位置
- **双击**：快速喂食

### 🎨 小鸟状态
| 状态 | 表现 |
|------|------|
| idle | 站立发呆，微微摇晃 |
| walk | 小脚交替走动 |
| fly | 翅膀扇动飞行 |
| eat | 低头啄食 |
| sleep | 闭眼睡觉，zzz |
| pet | 爱心眼微笑 |

## 技术栈

- **框架**: PyQt6
- **动画**: QPainter 2D 绘制
- **存储**: JSON 文件

## 开发

```bash
# 安装依赖
pip install -r requirements.txt

# 运行
python main.py
```

## 系统要求

- Windows / macOS / Linux
- Python 3.10+
- PyQt6 6.6+
